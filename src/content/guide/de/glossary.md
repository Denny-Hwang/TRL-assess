# Glossar

Begriffe mit Quellenangabe werden aus dieser Quelle im englischen Original zitiert; die übrigen sind
allgemein verständliche Definitionen.

## Die Bewertung

| Begriff               | Bedeutung                                                                                                                                                |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TRL**               | Technology Readiness Level (Technologiereifegrad): eine Skala von 1–9 dafür, wie weit eine Technologie demonstriert wurde, und in welcher Umgebung.      |
| **TRA**               | Technology Readiness Assessment: eine formale, _unabhängige_ Bewertung der CTEs eines Programms nach dem Verfahren einer Behörde. Dieses Tool ist keine. |
| **CTE**               | Critical Technology Element (kritisches Technologieelement): ein Teil des Systems, dessen Reife darüber entscheidet, ob das System funktioniert.         |
| **Lückenlosigkeit**   | Eine Stufe zählt nur, wenn jede Stufe darunter erreicht ist. Gilt in beiden Tiers.                                                                       |
| **Nachweisabdeckung** | _Erfüllte_ Kriterien mit mindestens einem nicht abgelehnten Nachweis ÷ _erfüllte_ Kriterien.                                                             |

## Umgebungen und Prüflinge

| Begriff                           | Bedeutung                                                                                                                                                                                                                         |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Relevante Umgebung**            | „Testing environment that simulates both the most important and most stressing aspects of the operational environment“ (`dod-tra-2025`, Table 2-3, S. 11). Angewendet auf eine Komponente bei TRL 5, ein System/Teilsystem bei 6. |
| **Einsatzumgebung**               | „Environment that addresses user operational requirements and specifications required of the final system to include platform/packaging“ (ebd.). Angewendet auf einen Prototyp bei TRL 7, das tatsächliche System bei 8.          |
| **Breadboard**                    | „Integrated components that provide a representation of a system/subsystem… typically configured for laboratory use… may resemble final system/subsystem in function only“ (ebd.).                                                |
| **Hohe / niedrige Realitätsnähe** | Hohe Realitätsnähe (high fidelity) „addresses form, fit, and function“; niedrige Realitätsnähe liefert kaum mehr als Informationen erster Ordnung (`dod-tra-2025`, Table 2-3, S. 11).                                             |

## Benachbarte Skalen

| Skala                                | Fragt                                                                                                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **ARL** (DOE, `doe-otc-arl-2025`)    | Was zwischen einer funktionierenden Technologie und ihrem Einsatz steht. Bewertet unter [Einführungsreife](/guide/arl). |
| **MRL** (DoD, `dod-mrl-matrix-2018`) | Lässt es sich produzieren — Prozess, Lieferkette, Personal, Qualität. Hier nicht bewertet.                              |
| **TPL** (NREL, `nrel-tpl`)           | Wie gut würde es im ausgereiften Zustand funktionieren. Hier nicht bewertet.                                            |
| **IRL / SRL**                        | Wie ausgereift sind die Schnittstellen zwischen den Elementen und das System. Hier nicht bewertet.                      |

## Sonstiges

| Begriff   | Bedeutung                                                                                                                                                                              |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FMECA** | Failure Modes, Effects and Criticality Analysis (Fehlermöglichkeits-, Einfluss- und Kritikalitätsanalyse).                                                                             |
| **CUI**   | Controlled Unclassified Information: eine Kennzeichnung der US-Regierung für Informationen, die schutzbedürftig, aber nicht eingestuft sind. Geben Sie niemals CUI in dieses Tool ein. |
