# Glossary

Terms marked with a source are quoted from it; the rest are plain-language definitions.

## The assessment

| Term                  | Meaning                                                                                                                                  |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **TRL**               | Technology Readiness Level: a 1–9 scale for how far a technology has been demonstrated, and in what environment.                         |
| **TRA**               | Technology Readiness Assessment: a formal, _independent_ evaluation of a programme's CTEs under an agency process. This tool is not one. |
| **CTE**               | Critical Technology Element: a part of the system whose maturity decides whether the system works.                                       |
| **Contiguity**        | A level counts only if every level below it is achieved. Applied in both tiers.                                                          |
| **Evidence coverage** | _Met_ criteria with at least one non-rejected evidence item ÷ _Met_ criteria.                                                            |

## Environments and articles

| Term                        | Meaning                                                                                                                                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Relevant environment**    | "Testing environment that simulates both the most important and most stressing aspects of the operational environment" (`dod-tra-2025`, Table 2-3, p. 11). Applied to a component at TRL 5, a system/subsystem at 6. |
| **Operational environment** | "Environment that addresses user operational requirements and specifications required of the final system to include platform/packaging" (ibid.). Applied to a prototype at TRL 7, the actual system at 8.           |
| **Breadboard**              | "Integrated components that provide a representation of a system/subsystem… typically configured for laboratory use… may resemble final system/subsystem in function only" (ibid.).                                  |
| **High / low fidelity**     | High fidelity "addresses form, fit, and function"; low fidelity gives little beyond first-order information (`dod-tra-2025`, Table 2-3, p. 11).                                                                      |

## Neighbouring scales

| Scale                                | Asks                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| **ARL** (DOE, `doe-otc-arl-2025`)    | What stands between a working technology and its use. Scored in [Adoption readiness](/guide/arl). |
| **MRL** (DoD, `dod-mrl-matrix-2018`) | Can it be produced — process, supply chain, workforce, quality. Not scored here.                  |
| **TPL** (NREL, `nrel-tpl`)           | How well would it perform if mature. Not scored here.                                             |
| **IRL / SRL**                        | How mature are the interfaces between elements, and the system. Not scored here.                  |

## Other

| Term      | Meaning                                                                                                                                                     |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FMECA** | Failure Modes, Effects and Criticality Analysis.                                                                                                            |
| **CUI**   | Controlled Unclassified Information: a U.S. Government designation for information needing safeguarding but not classified. Never enter CUI into this tool. |
