# 이 도구의 사용 방법

모든 작업은 브라우저에서 실행됩니다. 아무것도 업로드되지 않으며, 계정도 없습니다.

## Tier 1 — 빠른 추정 (약 5분)

1. **배경 정보.** 프로젝트, 기술, 평가자와 함께 교차 점검에 사용되는 _도달 환경_(E0–E4)과
   _제작 성숙도_(B0–B5)를 입력합니다.
2. **9개 질문, TRL 9부터.** 기술 전체를 기준으로 **예**, **아니요** 또는 **불확실**로 답합니다.
   키보드: `Y` `N` `U`로 답변, 화살표 키로 이동.
3. **결과.** 추정 TRL, 주장된 최고 수준, 교차 점검, 일관성 등급 및 플래그가 표시됩니다. 워크북
   또는 JSON을 다운로드합니다.

## Tier 2 — 증거 기반 평가

1. **CTE 식별** — [핵심기술요소](/guide/cte)를 참조하십시오. 시스템 요약에 반영되어야 하는 CTE를
   중요로 표시합니다.
2. 각 CTE에 대해 TRL 1부터 차례로 **기준을 평가**합니다.

:::figure status-legend:::

3. 기준 옆의 **관리**로 **증거를 첨부**합니다. 증거 없이 *충족*으로 표시된 필수 기준은 반영되지
   **않습니다**. [증거](/guide/evidence)를 참조하십시오.
4. **결과 확인:** 각 CTE의 TRL, 시스템 요약, 제한 요인 CTE, 미비 사항 목록.
5. **내보내기.** 워크북이 기록이 되며, 증거 패키지(.zip)에는 파일과 SHA-256 매니페스트가 추가로
   포함됩니다.

## 도입 준비도 — ARL

1. **범위.** 프로젝트, 기술 범위, 가치사슬 범위, 평가 기간 및 정책 환경.
2. 17개 차원 각각을 근거와 함께 **평가**하고, 프로젝트가 위험을 줄일 부분에는 프로젝트 종료 시점
   목표를 설정합니다.
3. **결과.** ARL 시작, ARL 종료 및 위험 프로파일. ARL 워크북 또는 JSON을 다운로드합니다.

*ARL 초기화*는 ARL 등급만 지웁니다. [도입 준비도](/guide/arl)를 참조하십시오.

## 저장, 공유, 삭제

|           |                                                                                                                             |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 자동 저장 | 이 브라우저에 저장: 평가는 `localStorage`, 증거 파일은 IndexedDB. 사이트 데이터를 지우면 함께 삭제됩니다.                   |
| 인계      | **JSON 다운로드** / **JSON 가져오기**로 파일 내용을 제외한 모든 것을 주고받을 수 있으며, 증거 패키지에는 파일이 포함됩니다. |
| 동기화    | 없음. 서로 다른 브라우저, 프로필, 기기는 저장소를 공유하지 않습니다.                                                        |
| 삭제      | **모든 로컬 데이터 삭제**는 이 브라우저에서 세션과 저장된 모든 파일을 제거합니다. 먼저 내보내십시오.                        |
