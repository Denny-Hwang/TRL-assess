# 용어집

출처가 표시된 용어는 해당 출처에서 인용한 것이며, 나머지는 쉬운 말로 풀어 쓴 정의입니다.

## 평가

| 용어                    | 의미                                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TRL**                 | 기술성숙도(Technology Readiness Level): 기술이 어느 단계까지, 어떤 환경에서 실증되었는지를 나타내는 1–9 척도.                                      |
| **TRA**                 | 기술성숙도 평가(Technology Readiness Assessment): 기관 절차에 따라 프로그램의 CTE를 공식적이고 _독립적으로_ 평가하는 것. 이 도구는 TRA가 아닙니다. |
| **CTE**                 | 핵심기술요소(Critical Technology Element): 그 성숙도가 시스템의 작동 여부를 좌우하는 시스템의 일부.                                                |
| **연속성** (contiguity) | 어떤 수준은 그 아래의 모든 수준이 달성된 경우에만 인정됩니다. 두 Tier 모두에 적용됩니다.                                                           |
| **증거 커버리지**       | 거부되지 않은 증거 항목이 하나 이상 있는 _충족_ 기준 ÷ _충족_ 기준.                                                                                |

## 환경과 시험 대상

| 용어                                          | 의미                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **유사 환경** (relevant environment)          | "Testing environment that simulates both the most important and most stressing aspects of the operational environment" (`dod-tra-2025`, Table 2-3, p. 11). (번역: 운용 환경의 가장 중요한 측면과 가장 가혹한 측면을 모두 모사하는 시험 환경) TRL 5에서는 구성품에, 6에서는 시스템/하위 시스템에 적용됩니다.                     |
| **운용 환경** (operational environment)       | "Environment that addresses user operational requirements and specifications required of the final system to include platform/packaging" (ibid.). (번역: 플랫폼/패키징을 포함하여 최종 시스템에 요구되는 사용자 운용 요구 사항과 사양을 반영하는 환경) TRL 7에서는 시제품에, 8에서는 실제 시스템에 적용됩니다.                  |
| **브레드보드** (breadboard)                   | "Integrated components that provide a representation of a system/subsystem… typically configured for laboratory use… may resemble final system/subsystem in function only" (ibid.). (번역: 시스템/하위 시스템을 표현하는 통합된 구성품… 일반적으로 실험실용으로 구성됨… 기능 면에서만 최종 시스템/하위 시스템과 유사할 수 있음) |
| **고충실도 / 저충실도** (high / low fidelity) | 고충실도는 "addresses form, fit, and function"(번역: 형태, 결합, 기능을 다룸)이며, 저충실도는 1차적인 정보 이상을 거의 제공하지 않습니다(`dod-tra-2025`, Table 2-3, p. 11).                                                                                                                                                     |

## 인접 척도

| 척도                                 | 묻는 것                                                                                            |
| ------------------------------------ | -------------------------------------------------------------------------------------------------- |
| **ARL** (DOE, `doe-otc-arl-2025`)    | 작동하는 기술과 실제 활용 사이를 가로막는 것은 무엇인가. [도입 준비도](/guide/arl)에서 산정합니다. |
| **MRL** (DoD, `dod-mrl-matrix-2018`) | 생산할 수 있는가 — 공정, 공급망, 인력, 품질. 여기서는 산정하지 않습니다.                           |
| **TPL** (NREL, `nrel-tpl`)           | 성숙했을 때 얼마나 좋은 성능을 낼 것인가. 여기서는 산정하지 않습니다.                              |
| **IRL / SRL**                        | 요소 간 인터페이스와 시스템은 얼마나 성숙했는가. 여기서는 산정하지 않습니다.                       |

## 기타

| 용어      | 의미                                                                                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FMECA** | 고장 모드, 영향 및 치명도 분석(Failure Modes, Effects and Criticality Analysis).                                                                                |
| **CUI**   | 통제 대상 비기밀 정보(Controlled Unclassified Information): 기밀은 아니지만 보호가 필요한 정보에 대한 미국 정부의 지정. CUI는 이 도구에 절대 입력하지 마십시오. |
