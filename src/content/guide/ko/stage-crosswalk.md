# 단계 대응표

> **공식 표준이 아닌 참조 모델입니다.** 단계 모델은 조직마다 다릅니다. 의사소통 용도로 사용하고,
> TRL 점수 산정의 근거로 사용하지 마십시오.

일반적인 하드웨어 개발 단계 모델 하나를 TRL에 대응시킨 것입니다.

:::figure stage-crosswalk:::

| 단계 | 개발 용어              | 일반적인 TRL | 주요 목표                                                          |
| ---- | ---------------------- | ------------ | ------------------------------------------------------------------ |
| 0    | 개념                   | 1–2          | 기회와 기술적으로 신뢰할 수 있는 접근 방식을 정의합니다.           |
| 1    | 부품 수준 평가         | 2–3          | 핵심 부품을 선정하고, 한계, 편차, 통합 위험을 파악합니다.          |
| 2    | 개념 증명              | 3            | 근본적인 기술적 타당성을 실증합니다.                               |
| 3    | 브레드보드 시제품      | 3–4          | 신호 체인, 전자 회로, 알고리즘, 펌웨어, 방법을 개발합니다.         |
| 4    | 보드 수준 시제품 (PCB) | 4            | 맞춤형 전자 회로, 레이아웃, 노이즈, 전원, 인터페이스를 검증합니다. |
| 5    | 통합 시제품            | 5            | 대표적인 조건에서 종단 간 기능을 검증합니다.                       |
| 6    | 소형화 시제품          | 5–6          | 폼 팩터, 무게, 열 특성, 패키징, 사용성을 검증합니다.               |
| 7    | 양산 지향 시제품       | 6–7          | 설계 검증, 신뢰성, 규제 및 제조 준비도를 뒷받침합니다.             |
| 8    | 시범 생산 빌드         | 7–8          | 제조 가능성, 수율, 교정, 출하 검사, 공급망을 확인합니다.           |
| 9    | 기술 이전 / 라이선싱   | 8–9          | 파트너가 제품을 인증, 제조, 판매, 지원할 수 있도록 합니다.         |

## 범위가 넓은 이유

단계는 무엇을 **제작했는지**를 말하고, TRL은 무엇을 **어디에서 실증했는지**를 말합니다. 벤치에서만
시험한 소형화 시제품은 TRL 4이고, 유사 환경에서 시험했다면 5, 시스템에 통합하여 그곳에서
실증했다면 6입니다. 8–9단계는 대부분 제조와 상업화에 관한 문제이며, TRL은 이를 측정하지 않습니다.
