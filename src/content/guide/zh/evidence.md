# 证据

标记为*符合*但没有可用证据的必需准则**不**计入。

## 什么算作证据

评审人员无需询问您就能查验的任何东西。

| 类型 | 有力 | 薄弱 |
| --- | --- | --- |
| 文档 | 注明试验件、条件、日期和操作人员的已签署试验报告 | 无日期、无署名的评审笔记 |
| 试验数据 | 数据文件，外加条件和验收准则 | 坐标轴未标注的曲线图截图 |
| 代码仓库 | URL **加上固定的提交 SHA**、路径和标签 | 指向 `main` 的链接 |
| 图纸/CAD | 版本与试验件相符的已发布图纸 | 幻灯片中无标题的草图 |
| 照片/视频 | 带比例尺、注明日期的试验件试验照片 | 渲染图 |
| 出版物（DOI） | 确实涵盖该申报内容的 DOI | 相关但不同的器件的 DOI |
| 网页链接 | 稳定的公开页面——设施、标准、数据集 | 搜索结果 URL，或需要登录的页面 |
| 其他 | 校准证书、审核记录 | “见共享盘” |

记录试验件及其版本、日期、操作人员、条件、验收准则和结果——包括失败。代码仓库链接需要一个 7–40 个字符的提交 SHA 和一个路径。

## 相关环境与运行环境

这一区别将 TRL 5/6 与 7/8 区分开来。

:::figure environment-fidelity:::

- **相关环境**是 "a set of stressing conditions, representative of the full spectrum of intended operational employments"（译：一组代表预期运行使用全部范围的应力条件），作用于作为部件一部分（TRL 5）或作为系统/子系统一部分（TRL 6）的要素——`dod-tra-2025`，p. 12。
- **运行环境**是 "a set of conditions, representative of the full spectrum of employments"（译：一组代表使用全部范围的条件），作用于原型（TRL 7）或实际系统（TRL 8）——`dod-tra-2025`，p. 13。

“全部范围”意味着一次有利的试验是不够的。

## 标识

*公开*、*内部（不受限）*，或**敏感——仅作引用**；对于后者，本工具**拒绝存储文件**：请改为记录标题、保管人和参考编号。切勿输入涉密、受出口管制或 CUI 内容。

## 核验

每个条目的状态为**未核验**、**已核验**或**已驳回**，并附核验人和日期。只有*已驳回*会影响评分：已驳回的证据会被排除，因此仅依赖该证据的准则将不再满足。
