# 术语表

标注了来源的术语引自该来源（保留英文原文，括号内为译文）；其余为通俗语言的定义。

## 评估

| 术语           | 含义                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **TRL**        | 技术成熟度等级（Technology Readiness Level）：一个 1–9 级的标尺，表示一项技术已得到多大程度的演示，以及是在什么环境中演示的。        |
| **TRA**        | 技术成熟度评价（Technology Readiness Assessment）：按照某一机构的流程，对一个计划的 CTE 进行的正式的、*独立的*评价。本工具不是 TRA。 |
| **CTE**        | 关键技术要素（Critical Technology Element）：系统中其成熟度决定系统能否工作的那一部分。                                              |
| **连续性**     | 只有当其下每一级都已达到时，某一等级才计入。两个层级均适用。                                                                         |
| **证据覆盖率** | 至少有一项未被驳回证据的*符合*准则 ÷ *符合*准则。                                                                                    |

## 环境与试验件

| 术语            | 含义                                                                                                                                                                                                                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **相关环境**    | "Testing environment that simulates both the most important and most stressing aspects of the operational environment"（译：模拟运行环境中最重要和应力最大的各方面的试验环境）（`dod-tra-2025`，Table 2-3，p. 11）。在 TRL 5 用于部件，在 TRL 6 用于系统/子系统。                             |
| **运行环境**    | "Environment that addresses user operational requirements and specifications required of the final system to include platform/packaging"（译：满足用户运行要求以及最终系统（包括平台/封装）所需规格的环境）（ibid.）。在 TRL 7 用于原型，在 TRL 8 用于实际系统。                              |
| **面包板**      | "Integrated components that provide a representation of a system/subsystem… typically configured for laboratory use… may resemble final system/subsystem in function only"（译：集成在一起、用以表现系统/子系统的部件……通常按实验室使用配置……可能仅在功能上与最终系统/子系统相似）（ibid.）。 |
| **高/低逼真度** | 高逼真度 "addresses form, fit, and function"（译：涉及形状、配合和功能）；低逼真度除一阶信息外提供的信息很少（`dod-tra-2025`，Table 2-3，p. 11）。                                                                                                                                            |

## 相邻的标尺

| 标尺                                  | 所问的问题                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| **ARL**（DOE，`doe-otc-arl-2025`）    | 在一项可行的技术与其实际应用之间还隔着什么。在[采用就绪度](/guide/arl)中评分。 |
| **MRL**（DoD，`dod-mrl-matrix-2018`） | 它能否被生产出来——工艺、供应链、人力、质量。本工具不评分。                     |
| **TPL**（NREL，`nrel-tpl`）           | 如果成熟，它的性能会有多好。本工具不评分。                                     |
| **IRL / SRL**                         | 要素之间的接口以及整个系统的成熟度如何。本工具不评分。                         |
