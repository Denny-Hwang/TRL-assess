# 框架与来源

TRL 如果脱离了评分所依据的框架，就没有多大意义。请在开始会话时选择框架；每次导出都会记录其标识和版本。

:::figure framework-relation:::

## `dod-tra-2025`——默认框架

**范围**。任何硬件、软件或工艺/流程要素。

**内容**。所含准则**逐字**转录自 DoD《Technology Readiness Assessment Guidebook》（2025 年 2 月）：硬件用 Table 2-1（pp. 6–7），软件用 Table 2-2（pp. 8–10），以及 Section 2 中的相关环境/运行环境准则（pp. 12–13）。第一层级问题将这些定义改写为问题（`adapted`）。

**需要了解的两点**：

1. **没有任何准则是必需的**。该指南未对准则进行分类，因此每个等级都标记为“无必需准则——需由评估人确认”，只要有一条适用准则已满足，该等级即为已达到。请自行判断该等级需要什么。
2. **`process` 类 CTE 使用硬件准则**，因为该指南只涵盖硬件和软件。这一对应关系是本工具的决定。

## `marine-energy-eere`——海洋能与海洋装置

**范围**。海洋能转换装置、海洋观测装置及其子系统。

**第一层级**。九个问题，改编自 DOE EERE 的 TRL 定义（`eere-r540-112-02`）。该文件只定义了 TRL 1–8，因此 TRL 9 的问题取自 `dod-tra-2025` 的 Table 2-1。

**第二层级**。采用 `dod-tra-2025` 的准则，并将每个 TRL 中界定该等级的准则设为必需，另加八项**剪裁**条目，全部为必需：风险登记册和 FMECA（TRL 4）；导电海水试验和环境极端条件（5）；将码头试验与开阔水域试验分开的试验计划，以及有记录的现场持续时间和故障（6）；面向量产的零件，以及有文件记录的校准程序和数据路径（7）；已实际运行过的、向观测计划提交数据的途径（8）。如果某项不适用，请将其标记为*不适用*并附说明。

剪裁条目的理由引用了 NREL 的海洋能风险框架（`nrel-me-risk`）和 GOOS《Framework for Ocean Observing》（`goos-foo`）；未复制其中的任何文本。

## `doe-otc-arl-2025`——采用就绪度

不是 TRL 框架。DOE《Adoption Readiness Assessment》（Version: April 2025）：17 个采用风险维度，以及将其换算为 ARL 的查询表，均**逐字**转录。与 TRL 分开评分，绝不与 TRL 合并；请参阅[采用就绪度](/guide/arl)。

## 出处

| `origin`   | 含义                               |
| ---------- | ---------------------------------- |
| `verbatim` | 从公有领域来源原样复制             |
| `adapted`  | 对来源措辞进行了重组，含义保持不变 |
| `tailored` | 不见于任何来源；由本框架添加       |

`adapted` 和 `tailored` 条目附有理由。ISO 16290:2013 仅按条款号引用；绝不复制其文本。

如果某条准则错误引用了其来源，请提交一个 **Criteria correction** issue，写明框架标识、条目标识、来源的原文内容以及页码。
