# 方法

不做任何加权，也不做任何推断。

## 第一层级规则

| 规则 | 作用 |
| --- | --- |
| **估算 TRL**（主要结果） | 等级 L *及其下每一级*都回答为“是”的最高等级 L。如果 TRL 1 不是“是”，则为“< TRL 1”。 |
| **申报的最高等级** | 单个“是”的最高等级，不考虑中断。 |
| **“不确定”绝不计为“是”** | “否”也不计入。TRL 3 处的一个“不确定”会将估算上限定为 TRL 2。 |
| **中断警示** | 当最高申报高于估算时触发；它会列出未确认的等级。 |
| **不确定警示** | 当最高申报及以下任一回答为“不确定”时触发。 |

**交叉核对。**构建成熟度（B0–B5）× 环境（E0–E4）给出一个建议 TRL。这是本工具的启发式方法，并非标准，仅用于一致性评级。

:::figure cross-check-matrix:::

**一致性评级。***低*：交叉核对与估算相差 3 或以上，或某个中断覆盖 2 个或以上等级。*高*：没有中断或不确定警示，且交叉核对与估算相差不超过 1。*中*：其余所有情况。它只评价内部一致性，不评价准确性。

## 第二层级规则

**适用性。**一项准则适用，除非它列出了类型（`hardware`、`software`、`process`）且这些类型不包括该 CTE 的类型。未设置类型的 CTE 适用所有准则。

**已满足。**状态为**符合**且至少关联一项未标记为*已驳回*的证据，或状态为**不适用**且附有非空的说明。其他情况均不算已满足——包括没有可用证据的*符合*。

:::figure evidence-decision:::

**等级已达到。**等级 L 的每条适用的*必需*准则均已满足，**并且**等级 L−1 已达到（等级 0 始终计为已达到）。位于未达到等级之上的等级显示为*已锁定*。

**没有**适用必需准则的等级，在至少一条适用准则已满足时即为已达到，并标记为“无必需准则——需由评估人确认”——`dod-tra-2025` 中的每个等级均属此类，因为它未将任何准则标记为必需。

**CTE 的 TRL。**已达到的最高等级；0 显示为“< TRL 1”。

**下一等级完成度。**在上一个等级：已满足的适用准则 ÷ 适用准则，二者均不含“不适用”。

**系统汇总。**所有标记为*关键*的 CTE 中的**最小** TRL，并列出起制约作用的 CTE；如果没有关键 CTE，则不计算。

**证据覆盖率。**按 CTE 计算：至少有一项未被驳回证据的*符合*准则 ÷ *符合*准则。

**层级差值。**第二层级汇总减去第一层级估算；当差值为 2 或以上时给出解释。

证据类型从不加权；只有*已驳回*的证据会改变评分。
