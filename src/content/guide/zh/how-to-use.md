# 如何使用本工具

所有功能都在您的浏览器中运行。不会上传任何内容，也无需账户。

## 第一层级——快速估算（约 5 分钟）

1. **背景信息。**项目、技术和评估人，以及*已达到的环境*（E0–E4）和*构建成熟度*（B0–B5），这两项用于交叉核对。
2. **九个问题，从 TRL 9 开始。**针对整个技术回答**是**、**否**或**不确定**。键盘操作：按 `Y` `N` `U` 作答，按方向键移动。
3. **结果。**估算 TRL、申报的最高等级、交叉核对、一致性评级和警示。下载工作簿或 JSON。

## 第二层级——基于证据的评估

1. **识别 CTE**——请参阅[关键技术要素](/guide/cte)。将应计入系统汇总的要素标记为关键。
2. **评估每个 CTE 的准则**，从 TRL 1 开始逐级向上：

:::figure status-legend:::

3. **附加证据**：点击准则旁的**管理**。标记为*符合*但没有证据的必需准则**不**计入。请参阅[证据](/guide/evidence)。
4. **阅读结果：**各 CTE 的 TRL、系统汇总、制约性 CTE 和差距清单。
5. **导出。**工作簿即为记录；证据包（.zip）另外附带文件及 SHA-256 清单。

## 采用就绪度——ARL

1. **范围。**项目、技术范围、价值链范围、时间框架和政策环境。
2. **评级**：对 17 个维度逐一评级并附理由；在项目将降低某项风险的地方，设定项目结束时的目标。
3. **结果。**ARL 起点、ARL 终点和风险概况。下载 ARL 工作簿或 JSON。

*重置 ARL* 只清除 ARL 评级。请参阅[采用就绪度](/guide/arl)。

## 保存、共享与清除

|  |  |
| --- | --- |
| 自动保存 | 保存到本浏览器：评估保存在 `localStorage`，证据文件保存在 IndexedDB。清除网站数据会删除它们。 |
| 移交 | **下载 JSON** / **导入 JSON** 可往返传递除文件内容以外的全部内容；证据包包含文件。 |
| 同步 | 无。不同的浏览器、配置文件和设备之间不共享存储。 |
| 清除 | **清除所有本地数据**会从本浏览器中删除会话及所有已存储的文件。请先导出。 |
