# このツールの使い方

すべてはブラウザー内で動作します。何もアップロードされず、アカウントもありません。

## Tier 1 — クイック推定（約 5 分）

1. **前提情報**。プロジェクト、技術、評価者に加え、クロスチェックに使う _到達した環境_（E0–E4）と _ビルド成熟度_（B0–B5）。
2. **9 つの質問、TRL 9 から**。技術全体について **はい**、**いいえ**、**不明** のいずれかで回答します。キーボード：`Y` `N` `U` で回答、矢印キーで移動。
3. **結果**。推定 TRL、申告された最高レベル、クロスチェック、整合性の評価、フラグ。ワークブックまたは JSON をダウンロードします。

## Tier 2 — エビデンスに基づく評価

1. **CTE を特定します** — [重要技術要素](/guide/cte)を参照してください。システムサマリーに算入すべきものを重要として指定します。
2. **各 CTE の基準を評価します**。TRL 1 から順に上へ進めます。

:::figure status-legend:::

3. 基準の横にある **管理** から **エビデンスを添付します**。エビデンスなしで _達成_ とされた必須基準は **数えられません**。[エビデンス](/guide/evidence)を参照してください。
4. **結果を読みます**。各 CTE の TRL、システムサマリー、制約となる CTE、ギャップ一覧。
5. **エクスポート**。ワークブックが記録となります。エビデンスパッケージ（.zip）には、ファイルと SHA-256 マニフェストが加わります。

## 導入準備度 — ARL

1. **範囲**。プロジェクト、技術の範囲、バリューチェーンの範囲、評価の対象期間、政策環境。
2. 17 の観点それぞれを根拠とともに **評定** し、プロジェクトでリスクを低減する観点にはプロジェクト終了時の目標を設定します。
3. **結果**。ARL 開始、ARL 終了、リスクプロファイル。ARL ワークブックまたは JSON をダウンロードします。

_ARL をリセット_ で消去されるのは ARL の評定だけです。[導入準備度（ARL）](/guide/arl)を参照してください。

## 保存、共有、消去

|          |                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 自動保存 | このブラウザーに保存：評価は `localStorage`、エビデンスファイルは IndexedDB。サイトデータを消去すると削除されます。                        |
| 引き継ぎ | **JSON をダウンロード** / **JSON をインポート** で、ファイルの内容以外はすべて往復できます。エビデンスパッケージにはファイルが含まれます。 |
| 同期     | ありません。異なるブラウザー、プロファイル、デバイスの間でストレージは共有されません。                                                     |
| 消去     | **ローカルデータをすべて消去** は、このブラウザーからセッションと保存済みのすべてのファイルを削除します。先にエクスポートしてください。    |
