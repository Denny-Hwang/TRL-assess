# エビデンス

有効なエビデンスがないまま _達成_ とされた必須基準は、**数えられません**。

:::figure evidence-decision:::

## エビデンスとして認められるもの

レビュアーがあなたに尋ねなくても確認できるものすべてです。

| 種類             | 強い                                                         | 弱い                                         |
| ---------------- | ------------------------------------------------------------ | -------------------------------------------- |
| 文書             | 試験対象物、条件、日付、実施者を明記した署名入りの試験報告書 | 日付も作成者もないレビューメモ               |
| 試験データ       | データファイルと、その条件および合否判定基準                 | 軸ラベルのないグラフのスクリーンショット     |
| コードリポジトリ | URL **と固定したコミット SHA**、パス、タグ                   | `main` へのリンク                            |
| 図面/CAD         | 試験対象物と一致するリビジョンの、リリース済み図面           | スライド内の無題のスケッチ                   |
| 写真/動画        | 試験中の対象物を写した、スケール入りの日付付き写真           | レンダリング画像                             |
| 出版物（DOI）    | その主張を実際に裏付ける DOI                                 | 関連はあるが別のデバイスについての DOI       |
| Web リンク       | 安定した公開ページ — 施設、規格、データセット                | 検索結果の URL、またはログインが必要なページ |
| その他           | 校正証明書、監査記録                                         | 「共有ドライブを参照」                       |

試験対象物とそのリビジョン、日付、実施者、条件、合否判定基準、結果を記録してください。不合格も含めます。リポジトリへのリンクには、7〜40 文字のコミット SHA とパスが必要です。

## 関連環境と運用環境

この区別が、TRL 5/6 と 7/8 を分けます。

:::figure environment-fidelity:::

- **関連環境** とは "a set of stressing conditions, representative of the full spectrum of intended operational employments"（訳：意図された運用の全範囲を代表する、負荷の厳しい一連の条件）であり、構成要素の一部としての要素（TRL 5）またはシステム/サブシステム（TRL 6）に適用されます — `dod-tra-2025`、p. 12。
- **運用環境** とは "a set of conditions, representative of the full spectrum of employments"（訳：運用の全範囲を代表する一連の条件）であり、プロトタイプ（TRL 7）または実システム（TRL 8）に適用されます — `dod-tra-2025`、p. 13。

「全範囲（full spectrum）」とは、条件の良い試験 1 回では不十分だということです。

## 区分表示

_公開_、_内部（制限なし）_、または **機微 — 参照のみ** のいずれかです。「機微 — 参照のみ」の場合、ツールは **ファイルの保存を拒否します**。代わりにタイトル、管理者、参照番号を記録してください。秘密指定情報、輸出管理対象情報、CUI を入力してはいけません。

## 検証

各項目は **未検証**、**検証済み**、**却下** のいずれかで、検証者と日付を伴います。スコアに影響するのは _却下_ だけです。却下されたエビデンスは除外されるため、それだけに依拠している基準は充足されなくなります。
