# Excel 出力

ワークブックは静的なスナップショットです。Microsoft Excel と LibreOffice で開くことができ、データの入力規則と条件付き書式が設定されています。

## 2 つのワークブック

:::figure sheet-map:::

- **`Criteria_Assessment`** — CTE × 基準ごとに 1 行。算出済みの _充足_（Satisfied）列があります。
- **`Evidence_Register`** — すべてのエビデンス項目に続いて、50 行の空白行（`EV-P001`…）があります。空白行には入力規則のリストと _開く_（Open）列の数式があらかじめ設定されています。
- **`Gap_Actions`** — 各 CTE の次のレベルで未充足の必須基準と、20 行の空白行。

## 導入準備度のワークブック

[ARL モジュール](/guide/arl)は `ARL_<project>_<timestamp>.xlsx` をエクスポートします。シートは `README`、`Summary`、`Scope`、`Risk_Assessment`（観点ごとに 1 行、ルーブリックのテキスト付き）、`ARL_Lookup`（開始と目標のセルに印付き）、`References`、`Metadata` です。

## Excel でエビデンスを追加する

`Evidence_Register` で、次のいずれかを行います。

1. _場所 / URL_（Location / URL）に **URL** を入力する — _開く_ 列は "Open link" になります。
2. _ローカルファイル（相対パス）_（Local file (relative path)）に **ワークブックからの相対パス** を入力し、ファイルはワークブックと同じ場所の `evidence/` フォルダーに置く — _開く_ 列は "Open file" になります。
3. _区分表示_（Marking）を "Sensitive — reference only" に設定し、管理者と参照番号を記録する。

相対リンクを機能させるには、**ワークブックを開く前にパッケージ全体を展開し**、ワークブックだけでなくフォルダーごと移動してください。

## 値は再計算されません

算出されたすべての数値 — 充足、CTE の TRL、サマリー、完了度、カバレッジ、ARL — は、エクスポート時に書き込まれた **静的な値** です。Excel でステータスを編集しても、ほかは何も変わりません。アプリで評価を変更し（またはセッションの JSON を再インポートし）、もう一度エクスポートしてください。

`=`、`+`、`-`、`@` で始まるテキストは、数式として実行されないよう先頭にアポストロフィを付けて書き込まれます。
