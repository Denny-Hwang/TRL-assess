# 用語集

出典を示した用語はその出典からの引用です。それ以外は平易な言葉による定義です。

## 評価

| 用語                     | 意味                                                                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TRL**                  | 技術成熟度レベル（Technology Readiness Level）：技術がどこまで、どのような環境で実証されたかを示す 1〜9 の尺度。                                                  |
| **TRA**                  | 技術成熟度評価（Technology Readiness Assessment）：機関のプロセスのもとで、プログラムの CTE を正式かつ _独立して_ 評価するもの。このツールは TRA ではありません。 |
| **CTE**                  | 重要技術要素（Critical Technology Element）：その成熟度によってシステムが機能するかどうかが決まる、システムの一部分。                                             |
| **連続性**               | あるレベルが数えられるのは、その下のすべてのレベルが達成されている場合だけです。両方の Tier で適用されます。                                                      |
| **エビデンスカバレッジ** | 却下されていないエビデンス項目が少なくとも 1 つある _達成_ 基準 ÷ _達成_ 基準。                                                                                   |

## 環境と試験対象物

| 用語                    | 意味                                                                                                                                                                                                                                                                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **関連環境**            | "Testing environment that simulates both the most important and most stressing aspects of the operational environment"（訳：運用環境の最も重要な側面と最も負荷の厳しい側面の両方を模擬する試験環境）（`dod-tra-2025`、Table 2-3、p. 11）。TRL 5 では構成要素に、6 ではシステム/サブシステムに適用されます。                                   |
| **運用環境**            | "Environment that addresses user operational requirements and specifications required of the final system to include platform/packaging"（訳：プラットフォーム/パッケージングを含め、最終システムに求められるユーザーの運用要求と仕様に対応する環境）（ibid.）。TRL 7 ではプロトタイプに、8 では実システムに適用されます。                    |
| **ブレッドボード**      | "Integrated components that provide a representation of a system/subsystem… typically configured for laboratory use… may resemble final system/subsystem in function only"（訳：システム/サブシステムを表現する統合された構成要素…通常は実験室での使用向けに構成され…機能の面でのみ最終システム/サブシステムに似ている場合がある）（ibid.）。 |
| **高忠実度 / 低忠実度** | 高忠実度は "addresses form, fit, and function"（訳：形状、適合、機能に対応する）。低忠実度は、一次的な情報以上のものをほとんど与えません（`dod-tra-2025`、Table 2-3、p. 11）。                                                                                                                                                                |

## 隣接する尺度

| 尺度                                  | 問うこと                                                                                 |
| ------------------------------------- | ---------------------------------------------------------------------------------------- |
| **ARL**（DOE、`doe-otc-arl-2025`）    | 動作する技術とその利用との間に何があるか。[導入準備度（ARL）](/guide/arl)で採点します。  |
| **MRL**（DoD、`dod-mrl-matrix-2018`） | 生産できるか — プロセス、サプライチェーン、人員、品質。ここでは採点しません。            |
| **TPL**（NREL、`nrel-tpl`）           | 成熟した場合にどの程度の性能を発揮するか。ここでは採点しません。                         |
| **IRL / SRL**                         | 要素間のインターフェース、およびシステムがどの程度成熟しているか。ここでは採点しません。 |

## その他

| 用語      | 意味                                                                                                                                                                 |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FMECA** | 故障モード・影響・致命度解析（Failure Modes, Effects and Criticality Analysis）。                                                                                    |
