# フレームワークと出典

TRL は、どのフレームワークで採点したかがわからなければほとんど意味を持ちません。フレームワークはセッションの開始時に選択します。すべてのエクスポートに、その ID とバージョンが記録されます。

## `dod-tra-2025` — デフォルト

**範囲**。ハードウェア、ソフトウェア、プロセスのあらゆる要素。

**内容**。DoD Technology Readiness Assessment Guidebook（2025 年 2 月）から **原文どおり** に転記した基準：ハードウェアは Table 2-1（pp. 6–7）、ソフトウェアは Table 2-2（pp. 8–10）、関連環境/運用環境の基準は Section 2（pp. 12–13）。Tier 1 の質問は、これらの定義を質問の形に言い換えたものです（`adapted`）。

**知っておくべき 2 つの点：**

1. **必須のものは何もありません**。ガイドブックは基準を分類していないため、すべてのレベルに「必須基準なし — 評価者による確認が必要です」のフラグが立ち、適用される基準が 1 つ充足された時点で達成となります。そのレベルに何が必要かは、あなた自身が判断してください。
2. **`process` の CTE にはハードウェアの基準が提示されます**。ガイドブックはハードウェアとソフトウェアしか扱っていないためです。この対応付けは、このツールによる判断です。

## `marine-energy-eere` — 海洋エネルギーと海洋デバイス

**範囲**。海洋エネルギー変換装置、海洋観測デバイス、およびそれらのサブシステム。

**Tier 1**。DOE EERE の TRL 定義（`eere-r540-112-02`）を再構成した 9 つの質問。この文書は TRL 1〜8 しか定義していないため、TRL 9 の質問は `dod-tra-2025` の Table 2-1 によります。

**Tier 2**。`dod-tra-2025` の基準のうち、各 TRL でレベルを定義する基準を必須とし、さらにすべて必須の **テーラリング** 項目 8 つを加えたもの：リスク登録簿と FMECA（TRL 4）、導電性のある海水での試験と環境の極限条件（5）、岸壁での試験と外洋での試験を区別した試験計画、および記録された現地展開期間と故障（6）、量産を想定した部品、および文書化された校正手順とデータ経路（7）、観測プログラムへのデータ提出経路の実運用（8）。該当しない項目は、理由を記載して _該当なし_ としてください。

テーラリング項目の根拠では、NREL の海洋エネルギーのリスクフレームワーク（`nrel-me-risk`）と GOOS Framework for Ocean Observing（`goos-foo`）を引用しています。これらのテキストは転載していません。

## `doe-otc-arl-2025` — 導入準備度

TRL のフレームワークではありません。DOE の _Adoption Readiness Assessment_（Version: April 2025）です。17 の導入リスク観点と、それを ARL に変換する参照表を **原文どおり** に転記しています。TRL とは別に採点され、統合されることはありません。[導入準備度（ARL）](/guide/arl)を参照してください。

## 出所の区分

| `origin`   | 意味                                               |
| ---------- | -------------------------------------------------- |
| `verbatim` | パブリックドメインの出典から正確に複写したもの     |
| `adapted`  | 出典の文言を再構成したもの。意味は保たれています   |
| `tailored` | どの出典にもないもの。フレームワークが追加した項目 |

`adapted` と `tailored` の項目には根拠が付いています。ISO 16290:2013 は条項番号でのみ引用し、そのテキストを転載することはありません。

基準が出典を誤って引用している場合は、フレームワーク ID、項目 ID、出典の記載内容、ページ番号を添えて **Criteria correction** の Issue を作成してください。
