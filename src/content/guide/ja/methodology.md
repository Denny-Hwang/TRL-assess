# 方法論

重み付けは一切行わず、推測も一切行いません。

## Tier 1 のルール

| ルール                                  | 内容                                                                                                                       |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **推定 TRL**（見出しの数値）            | L と *その下のすべてのレベル* に「はい」と回答された、最も高いレベル L。TRL 1 が「はい」でない場合は「< TRL 1」。          |
| **申告された最高レベル**                | 途切れを無視した、単独の「はい」の最高レベル。                                                                             |
| **「不明」が「はい」として数えられることはない** | 「いいえ」も同様です。TRL 3 で「不明」があると、推定値の上限は TRL 2 になります。                                   |
| **ギャップのフラグ**                    | 最高申告値が推定値を上回るときに立ちます。確認されていないレベルを示します。                                               |
| **不明のフラグ**                        | 最高申告値以下のいずれかの回答が「不明」のときに立ちます。                                                                 |

**クロスチェック**。ビルド成熟度（B0–B5）× 環境（E0–E4）から TRL が推奨されます。これはこのツールのヒューリスティックであって標準ではなく、整合性の評価にのみ用いられます。

:::figure cross-check-matrix:::

**整合性の評価**。*低*：クロスチェックが推定値と 3 以上異なる、またはギャップが 2 レベル以上にわたる。*高*：ギャップのフラグも不明のフラグもなく、クロスチェックが推定値から 1 以内。*中*：それ以外のすべて。評価するのは内部的な整合性だけであり、正確さではありません。

## Tier 2 のルール

**適用性**。基準は、種類（`hardware`、`software`、`process`）を列挙していてそれが CTE の種類を除外している場合を除き、適用されます。種類が設定されていない CTE には、すべての基準が適用されます。

**充足**。ステータスが **達成** で、*却下* とされていないエビデンス項目が少なくとも 1 つリンクされている場合、またはステータスが **該当なし** で理由が空欄でない場合です。それ以外は充足されません。有効なエビデンスのない *達成* も同様です。

:::figure evidence-decision:::

**レベルの達成**。L で適用されるすべての *必須* 基準が充足され、**かつ** レベル L−1 が達成されていること（レベル 0 は常に達成とみなします）。未達成のレベルより上のレベルは *ロック中* と表示されます。

適用される必須基準が **1 つもない** レベルは、適用される基準が少なくとも 1 つ充足されたときに達成となり、「必須基準なし — 評価者による確認が必要です」というフラグが立ちます。何も必須としていない `dod-tra-2025` では、すべてのレベルがこれに該当します。

**CTE の TRL**。達成された最も高いレベル。0 は「< TRL 1」と表示されます。

**次レベルの完了度**。1 つ上のレベルにおける、充足された適用基準 ÷ 適用基準。いずれも「該当なし」を除きます。

**システムサマリー**。*重要* に指定された CTE 全体の **最小** TRL で、制約となる CTE を示します。重要な CTE がない場合は算出されません。

**エビデンスカバレッジ**。CTE ごとに、却下されていないエビデンス項目が少なくとも 1 つある *達成* 基準 ÷ *達成* 基準。

**Tier 間の差**。Tier 2 のサマリーから Tier 1 の推定値を引いた値で、2 以上の場合は説明が表示されます。

エビデンスの種類で重み付けすることはありません。スコアを変えるのは *却下* されたエビデンスだけです。
